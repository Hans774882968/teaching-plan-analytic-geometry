## 引言

今天在castelu大佬评论区看到这样一条评论：我一朋友在朋友圈发了BMI还精确到小数点后两位，于是成功用excel定位出唯一一组身高体重。感觉这是道有趣的算法题，遂赶紧氵期视频和小伙伴们分享~

我们不禁要问：能否仅根据BMI反推身高和体重？

## 建模前的约定

我们知道BMI的计算公式：

$$
B=\frac{w}{h^2}
$$

为了方便数学建模，不妨先结合现实生活进行一些约定：

1. 体重的单位是kg，所以精确到1位小数，比如114.5kg
2. BMI使用的身高的单位是米，所以身高精确到3位小数，比如1.919米
3. 有了前两条约定，B显然是有理数，不妨设为 $\frac{P}{Q}$

## 初步思路

进行上述约定后，凭Hans多年的算法竞赛经验（~~金（dǎ）牌（tiě）水平~~），一瞬间就想到，约定一个身高上限（因为很难见到3米以上的人类），便能直接枚举范围内所有可能的身高，用公式 $w=Bh^2$ 看何时能得到一位小数的体重即可。

虽然能解决问题，但局限性有点强啊……有没有更好的方法呢？有的。

## Hans的想法：质因数分解

回顾BMI的计算公式，令 $W=10w,\ H=1000h$ ，则W和H都为正整数，代入BMI公式：

$$
\frac{P}{Q}=\frac{w}{h^2}=\frac{\frac{W}{10}}{\left( \frac{H}{1000} \right)^2}=10^5 \frac{W}{H^2} \implies W=\frac{PH^2}{10^5Q} \tag{1}
$$

这里同学们不妨思考一下：为什么不变形为 $H^2$ 等于xxx，而是这样变形呢？

也就是说，我们希望**找到最小的正整数H，使得 $PH^2$ 是 $10^5Q$ 的倍数**，这就是道数论题了。为了方便，不妨设BMI已经是最简分数，即P和Q互素，于是P对倍数关系没有影响，问题转化为：

> 求最小的正整数H，使得 $H^2$ 是 $10^5Q$ 的倍数

这时，等式的分子只剩H，足够纯净，我们便不难想到：考虑 $D=10^5Q$ 的质因数分解

$$
D = p_1^{\alpha_1} p_2^{\alpha_2} \cdots p_k^{\alpha_k}
$$

为了让 $H^2$ 包含 $D$ 的所有质因数，$H$ 至少要包含 $\lceil \alpha_i / 2 \rceil$ 个 $p_i$ ，因此，最小的

$$
H = \prod_{i=1}^{k} p_i^{\lceil \alpha_i / 2 \rceil}
$$

对D质因数分解后立刻就能求出H，进而求出W。数据范围不太大的情况下，直接用试除法对D质因数分解即可，时间复杂度 $O(\sqrt{ D })$ 。最后，我们把P和Q互素的假设去掉，1式只需稍作修改：

$$
W=\frac{\frac{P}{g}H^2}{10^5 \frac{Q}{g}},\ g=gcd(P,Q)
$$

因为 $\frac{P}{g}$ 和 $\frac{Q}{g}$ 互素，所以只需要把上面假设的D改成 $D=10^5 \frac{Q}{g}$

完整代码：

```python
import math
from fractions import Fraction


def prime_factors(n):
    """对整数 n 进行质因数分解，返回字典 {素数: 幂次}"""
    factors = {}
    while n % 2 == 0:
        factors[2] = factors.get(2, 0) + 1
        n //= 2
    d = 3
    while d * d <= n:
        while (n % d) == 0:
            factors[d] = factors.get(d, 0) + 1
            n //= d
        d += 2
    if n > 1:
        factors[n] = factors.get(n, 0) + 1
    return factors


def find_exact_hw(bmi_value):
    """
    根据精确的有理数 BMI，构造出最小的一组
    身高精确到3位小数、体重精确到1位小数的 (h, w)
    """
    if isinstance(bmi_value, float):
        bmi_frac = Fraction(bmi_value).limit_denominator(10**9)
    else:
        bmi_frac = Fraction(bmi_value)

    P = bmi_frac.numerator
    Q = bmi_frac.denominator

    if P <= 0 or Q <= 0:
        raise ValueError("BMI 必须是正有理数")

    # 1. 计算有效分母 D = 100000 * Q / gcd(P, 100000 * Q)
    denom = 100000 * Q
    g = math.gcd(P, denom)
    D = denom // g

    # 2. 对 D 进行质因数分解
    factors = prime_factors(D)

    # 3. 构造最小的 H，使得 H^2 是 D 的倍数
    H = 1
    for p, alpha in factors.items():
        # 幂次向上取整：ceil(alpha / 2)
        power = (alpha + 1) // 2
        H *= (p ** power)

    # 4. 计算对应的 W = P * H^2 / (100000 * Q)
    # 因为 H 的构造保证了 H^2 是 D 的倍数，这里必定能整除
    W = (P * H * H) // (100000 * Q)

    # 还原为3位小数的身高和1位小数的体重
    h = H / 1000.0
    w = W / 10.0

    return h, w, H, W


if __name__ == "__main__":
    test_cases = [
        25,             # 整数
        18.5,           # 常见 BMI
        "3.14159",      # 字符串输入，避免浮点误差
        Fraction(1, 3),  # 分数 1/3
        Fraction(22, 7),  # 分数 22/7
        Fraction(560000, 29241),  # 56kg 1.71m
        Fraction(565000, 29241),  # 56.5kg 1.71m
        Fraction(65000, 3249),  # 58.5kg 1.71m
        Fraction(30625, 1681),  # 49kg 1.64m
        Fraction(5952000, 104329),  # 595.2kg 3.23m
        Fraction(28625000, 1846881),  # 114.5kg 2.718m
        114.514,
        810.1919,
    ]

    for bmi in test_cases:
        h, w, H, W = find_exact_hw(bmi)
        print(f"目标 BMI: {bmi} | 最小解: h={h:<5}米, w={w:<5}千克 | 验证: {w} / {h}^2 = {w / (h**2):.5f}")
```
